=== Fraction ===
Theme WordPress en blocs (FSE) pour Fraction.media — revue d'art, culture, politique et sociologie.
Editeur : SEFM — Societe des Editions Fraction Media.

== Heritage graphique ==
- Street Press : posters plein cadre, manchettes en capitales.
- Mediapart : rouge #D02C25 sur papier journal, lettrine rouge d'ouverture.
- CNAP : beige institutionnel, filets lourds, espacement museal.
- Brutalisme sovietique (constructivisme) : bande diagonale rouge de tetiere, blocs massifs sans radius, Oswald.

== Installation ==
1. Copier le dossier "fraction" dans wp-content/themes/ (ou uploader un zip du dossier via Apparence > Themes > Ajouter).
2. Activer le theme.
3. Dans l'editeur de site : regler le logo, le menu de navigation, le slogan du pied de page.
